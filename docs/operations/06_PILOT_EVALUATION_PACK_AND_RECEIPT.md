## 1. Pilot Tasks for Participating Officers

Each participating officer completes the following workflows without developer intervention:

1. **Author Flow:** Create/open an assigned `Draft` record, upload a valid `.pdf` or `.docx`, update version notes, and submit for review.
2. **Reviewer Flow:** Open `/officer/reviews`, complete all 6 verification checklist items, return one test version with a comment, and approve a corrected version.
3. **Publisher Flow:** Open `/officer/releases`, publish an approved version, verify it appears on `/` and `/records/:recordId`, and test supersession or withdrawal.
4. **Bulletin & Turnover Flow:** Compile an Update Bulletin (`/officer/bulletins`) and inspect a turnover package (`/officer/turnover`).
