# EA-CSC IIDGS Naming Glossary & Institutional Terminology

This glossary standardizes user-facing labels across the **EA-CSC Institutional Information and Document Governance System (IIDGS)** for the College of Engineering and Architecture Student Council, Catanduanes State University.

| Canonical Term                                             | Context / Route                        | Legacy / Prototype Term Removed                                           | Notes                                                                                                            |
| :--------------------------------------------------------- | :------------------------------------- | :------------------------------------------------------------------------ | :--------------------------------------------------------------------------------------------------------------- |
| **EA-CSC Institutional Information & Document Governance** | Header brand (`src/app/AppLayout.tsx`) | `EA-CSC Records System` + `DEVELOPMENT MODE — Fictional information only` | Reflects formal system title from the project proposal                                                           |
| **Public Library**                                         | `/`                                    | `Public library` + fictional prototype disclaimer                         | Verified current public releases, version history, and downloads                                                 |
| **Update Bulletins**                                       | `/bulletins`                           | `Bulletins`                                                               | Publicly issued compiled update bulletins                                                                        |
| **Officer Sign-In**                                        | `/login`                               | `Officer sign-in`                                                         | Authenticated council officer portal entry                                                                       |
| **Officer Workspace**                                      | `/officer`                             | `Officer workspace` + Slice prototype notice                              | Assigned records, Draft creation, upload staging, and version submission                                         |
| **Review Queue**                                           | `/officer/reviews`                     | `Review queue` + "follow in the next step" note                           | Six-point verification checklist (`Confirmed`, `Correction Required`, `Not Applicable`) and substantive approval |
| **Release Panel**                                          | `/officer/releases`                    | `Release panel`                                                           | Publication, scheduled release activation, supersession, and emergency withdrawal                                |
| **Bulletin Compiler**                                      | `/officer/bulletins`                   | `Compile Bulletin` + "follow in Slice 8B" note                            | Cutoff-pinned bulletin compilation, PDF preview, and archival issuance                                           |
| **Turnover**                                               | `/officer/turnover`                    | `Turnover`                                                                | End-of-term turnover package preparation, transfer, and incoming acknowledgment                                  |
| **Access Transfer**                                        | `/officer/admin/access`                | `Access transfer`                                                         | Role eligibility and officer access handover administration                                                      |
